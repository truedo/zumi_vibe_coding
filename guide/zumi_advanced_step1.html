STEP 1 · 연결하고 보기 · 기본 프롬프트
# ZUMI 로봇 카메라 웹앱 만들기 ## 시스템 구조 브라우저(HTML) ↔ WebSocket ↔ ESP32(주미 로봇) 서버 없음. HTML 파일 하나로만 동작. 같은 Wi-Fi 네트워크 필요. ## WebSocket 연결 방법 ws = new WebSocket('ws://' + ip + '/ws') ws.binaryType = 'arraybuffer' 연결 후 반드시 ws.send('stream') 전송 → 영상 스트리밍 시작 ## 영상 수신 방법 (반드시 이 방식으로) ws.onmessage = (event) => { const blob = new Blob([new Uint8Array(event.data)], {type:'image/jpeg'}); const url = URL.createObjectURL(blob); const img = new Image(); img.onload = () => { ctx.drawImage(img, 0, 0, w, h); URL.revokeObjectURL(url); }; img.src = url; } ## 필수 UI 요소 - IP 주소 입력창 + 연결 버튼 + 해제 버튼 - 연결 상태 표시 (연결됨 / 연결 안 됨) - 영상을 표시할 canvas (width=640, height=480) - HTML 파일 하나로만 동작 (서버 불필요) ## 결과물 조건 - HTML 파일 하나로 동작 - CSS/JavaScript 내부 포함 - Chrome에서 바로 실행 가능 - 별도 서버 불필요 ## 추가로 만들어줄 기능: (여기에 원하는 기능을 직접 적어주세요) 예시: - 전체화면 버튼 추가 - 사진 저장 기능 - 흑백 필터 버튼 - 화면에 현재 시간 표시 - 밝기/대비 슬라이더
💡 프롬프트를 복사한 다음, 노란 부분을 원하는 내용으로 바꿔서 AI에게 보내보세요. 결과물이 마음에 안 들면 "더 크게", "모바일 스타일로", "어둡게" 같이 추가 요청도 됩니다!
🎯 AI가 만들어준 HTML 파일을 다운로드 혹은 저장 → Chrome으로 열기 → 주미 IP 입력 → 완성!
🗂️ 실제 사용 순서
  1. 위 프롬프트를 복사해서 Claude 또는 ChatGPT, Gemini에 붙여넣기
  2. 노란 부분에 원하는 기능 작성 후 전송
  3. AI가 만들어준 HTML 파일을 다운로드하거나 저장
  4. Chrome 브라우저로 파일 열기
  5. 주미 IP 입력 → CONNECT → 영상 확인! 🎉
