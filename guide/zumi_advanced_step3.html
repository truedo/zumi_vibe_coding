함수 레퍼런스

🎮 기본 이동 (직접 조종용)

함수CMD파라미터설명
move_infinite 29 speed: 1~3dir: 0/1 계속 이동. 버튼 떼면 stop() 필수
dir: 0=전진, 1=후진
stop 25 - 즉시 정지
left_turn_quick 52 deg: 5~360 (5단위) 빠른 좌회전. 내부에서 deg÷5 변환
right_turn_quick 53 deg: 5~360 (5단위) 빠른 우회전. 내부에서 deg÷5 변환
# 패킷 구조 move_infinite(speed, dir) → [24][52][29][00][speed][00][dir] stop() → [24][52][25][00] left_turn_quick(deg) → [24][52][52][00][deg/5] (90도 → 18) right_turn_quick(deg) → [24][52][53][00][deg/5]

📐 정밀 이동 (거리 / 각도 지정)

함수CMD파라미터설명
forward_dist 26 speed: 1~3dist: 0~300cm 지정 거리 전진 후 자동 정지
reverse_dist 26 speed: 1~3dist: 0~300cm 지정 거리 후진 후 자동 정지
left_turn 70 speed: 1~3deg: 각도 정밀 좌회전 (느리지만 정확)
right_turn 70 speed: 1~3deg: 각도 정밀 우회전 (느리지만 정확)
forward_dist(speed, dist) → [24][52][26][00][speed][dist][0] (dir=0 전진) reverse_dist(speed, dist) → [24][52][26][00][speed][dist][1] (dir=1 후진) left_turn(speed, deg) → [24][52][70][00][speed][deg_low][deg_high][0] right_turn(speed, deg) → [24][52][70][00][speed][deg_low][deg_high][1]

〰️ 특수 이동 (자동화)

함수CMD파라미터설명
linefollower_infinite 30 speed: 1~3 검은 선을 계속 따라감. stop()으로 멈춤
linefollower 101 speed: 1~3time: 0~25초 지정 시간 동안 라인 따라가기
time=0이면 교차로까지
linefollower_distance 28 speed: 1~3dist: 0~255cm 지정 거리만큼 라인 따라가기
go_sensor 100 speed: 1~3senL/R: 0~255 전방 센서 감지 시 자동 정지
기본값 150 권장
linefollower_infinite(speed) → [24][52][30][00][speed] linefollower(speed,...,time) → [24][52][101][00][speed][BL][BR][BC][time×10] linefollower_distance(sp,dist) → [24][52][28][00][speed][dist] go_sensor(speed, senL, senR) → [24][52][100][00][speed][senL][senR]
💡 라인트레이서 센서값 팁: senBL/BR/BC 기본값 100을 사용하세요. 바닥 색상에 따라 50~150 사이로 조정이 필요할 수 있어요.

# ZUMI 로봇 이동 제어 웹앱 만들기 ## 시스템 구조 브라우저(HTML) ↔ WebSocket(ws://IP/ws) ↔ ESP32(주미 로봇) 서버 없음. HTML 파일 하나로만 동작. ## 패킷 빌더 function buildPacket(cmd, ...params) { const buf = new Uint8Array(4 + params.length); buf[0]=0x24; buf[1]=0x52; buf[2]=cmd; buf[3]=0x00; params.forEach((v,i) => buf[4+i]=v); return buf.buffer; } ## 이동 명령어 // 기본 이동 전진(무한): CMD=29, params=[speed, 0, 0] speed: 1~3 후진(무한): CMD=29, params=[speed, 0, 1] 정지: CMD=25, params=[] 좌회전(빠른): CMD=52, params=[deg/5] deg: 5~360 (5단위) 우회전(빠른): CMD=53, params=[deg/5] // 정밀 이동 (거리 지정) 전진(거리): CMD=26, params=[speed, dist, 0] dist: 0~300cm 후진(거리): CMD=26, params=[speed, dist, 1] 좌회전(정밀): CMD=70, params=[speed, deg_low, deg_high, 0] 우회전(정밀): CMD=70, params=[speed, deg_low, deg_high, 1] deg_low = deg < 256 ? deg : deg%256 deg_high = deg < 256 ? 0 : Math.floor(deg/256) // 특수 이동 라인트레이서(무한): CMD=30, params=[speed] 라인트레이서(시간): CMD=101, params=[speed, senBL, senBR, senBC, time×10] senBL/BR/BC 기본값=100, time: 0~25초 라인트레이서(거리): CMD=28, params=[speed, dist] 장애물 감지 정지: CMD=100, params=[speed, senL, senR] senL/R 기본값=150 ## 전진/후진 버튼 패턴 (누르는 동안만 이동) btn.addEventListener('mousedown', () => sendRaw(buildPacket(29, speed, 0, dir))); btn.addEventListener('mouseup', () => sendRaw(buildPacket(25))); btn.addEventListener('mouseleave',() => sendRaw(buildPacket(25))); btn.addEventListener('touchstart',() => sendRaw(buildPacket(29, speed, 0, dir))); btn.addEventListener('touchend', () => sendRaw(buildPacket(25))); ## 기본 UI (필수 포함) - IP 입력 + 연결 버튼 + 연결 상태 표시 - 영상 스트리밍 canvas (640×480) ws.binaryType='arraybuffer', 연결 후 ws.send('stream') 수신: Blob → Image → canvas.drawImage ## 결과물 조건 - HTML 파일 하나로 동작 - CSS/JavaScript 내부 포함 - Chrome에서 바로 실행 가능 - 별도 서버 불필요 ## 추가로 만들어줄 기능: (여기에 원하는 것을 직접 적어주세요) 예시: - WASD 키보드 + D-PAD 버튼 조종 - 속도 슬라이더 (1~3) - 거리/각도 슬라이더로 정밀 이동 - 라인트레이서 시작/정지 버튼 - 정사각형 자동 이동 버튼
💡 Step 1·2 앱이 있다면 "기존 HTML 코드에 이동 기능을 추가해줘"라고 하고 코드를 같이 붙여넣으세요!
