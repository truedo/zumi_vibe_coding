💡 LED 제어

함수파라미터설명
led_control r: 0~10g: 0~10b: 0~10 RGB 색상으로 LED 켜기
0=끔, 10=최대 밝기
led_pattern pattern: 0~6time: 초(float) 0:유지 1:깜빡 2:두번깜빡 3:밝아졌다어두워짐
4:점점어두워짐 5:점점밝아짐 6:무지개
# 패킷 구조 led_control(r,g,b) → [0x24][0x52][10][0x00][r][g][b] (CMD=10, r/g/b 각 0~10) led_pattern(p,t) → [0x24][0x52][201][0x00][pattern][t_high][t_low] (CMD=201, time ms 변환)

🔊 사운드

함수파라미터사운드 목록

4:경적1 5:경적2 6:사이렌 7:성공

📺 LCD 텍스트

함수파라미터설명
display_text text: strnewline: 0/1 화면에 텍스트 새로 출력 (최대 27바이트)
display_text_add text: strnewline: 0/1 기존 텍스트에 이어서 추가 출력
display_text_clear - 화면 텍스트 전체 지우기
display_text_set color: 0~22size: 0~5 텍스트 색상(1=흰색)과 크기 설정
display_text_pos pos_x: intpos_y: int 텍스트 출력 위치 설정 (픽셀 단위)
display_text("Hello") → [0x24][0x52][230][0x00][H][e][l][l][o][0x00] (CMD=230) display_text_set(1,3) → [0x24][0x52][231][0x00][color][size][0][0][0] (CMD=231)

# ZUMI 로봇 표현 기능 웹앱 만들기 ## 시스템 구조 브라우저(HTML) ↔ WebSocket(ws://IP/ws) ↔ ESP32(주미 로봇) 서버 없음. HTML 파일 하나로만 동작. ## 패킷 구조 [0x24][0x52][command][0x00][param1]...[paramN] function buildPacket(cmd, ...params) { const buf = new Uint8Array(4 + params.length); buf[0]=0x24; buf[1]=0x52; buf[2]=cmd; buf[3]=0x00; params.forEach((v,i) => buf[4+i]=v); return buf.buffer; } ## 표현 기능 명령어 // LED (r,g,b 각 0~10) LED 색상: CMD=10, params=[r, g, b] LED 패턴: CMD=201, params=[pattern, time_high, time_low] 패턴: 0=유지 1=깜빡 2=두번깜빡 3=밝아졌다어두워짐 4=점점어두워짐 5=점점밝아짐 6=무지개 time: ms 단위, 예) 1000ms = time_high=3, time_low=232 // 사운드 사운드: CMD=242, params=[sound] 0=고양이 1=셔터 2=실패1 3=실패2 4=경적1 5=경적2 6=사이렌 7=성공 // LCD 텍스트 (UTF-8, 최대 27바이트) 텍스트 출력: CMD=230, 이후 UTF-8 문자열 바이트 + 0x00 텍스트 추가: CMD=232, 이후 UTF-8 문자열 바이트 + 0x00 텍스트 설정: CMD=231, params=[color, size, 0, 0, 0] color:(기본값:1) 0=변경안함, 1=흰색, 2=검정, 3=남색, 4=파랑, 5=하늘색, 6=청록색, 7=틸, 8=초록, 9=연두, 10=라임, 11=노랑, 12=호박색, 13=주황, 14=진주황, 15=갈색, 16=청회색, 17=회색 size: (기본값:5) 0=변경안함 1~5 // 텍스트 전송 제약 조건 및 확장 요구사항 기본적인 텍스트 전송 방식은 아래 sendText 예시를 따르되, 하드웨어 버퍼 한계(최대 11바이트)를 극복할 수 있는 '스마트 분할 전송 엔진'으로 고도화해줘. [핵심 제약 조건] 1. 하드웨어 버퍼 제한으로 인해 한 번에 보낼 수 있는 순수 데이터(Payload)는 최대 11바이트(let endIndex = currentIndex + 11)야. 2. 메시지가 11바이트보다 길면, TextEncoder로 변환된 바이트 배열을 11바이트 단위로 자동 슬라이싱(Chunking)해야 해. 3. 첫 번째 조각은 CMD 230(새로 출력)으로 보내고, 남은 바이트의 메시지 조각들은 CMD 232(추가 출력)로 연속해서 보내야 해. 4. 패킷이 연달아 가면 ESP32 수신 버퍼가 씹힐 수 있으므로, 각 조각 패킷 전송 사이에 100ms의 시간 지연(setTimeout 등을 활용한 재귀 루프)을 반드시 부여해줘. // 기본 텍스트 전송 참고 스크립트 function sendText(text) { const encoded = new TextEncoder().encode(text); const buf = new Uint8Array(4 + encoded.length + 1); buf[0]=0x24; buf[1]=0x52; buf[2]=230; buf[3]=0x00; buf.set(encoded, 4); buf[4 + encoded.length] = 0x00; ws.send(buf.buffer); } ## 기본 UI 포함 요소 - IP 입력 + 연결 버튼 + 상태 표시 - 영상 스트리밍 canvas (640×480) ws.binaryType='arraybuffer', 연결 후 ws.send('stream') 수신: Blob → Image → canvas.drawImage ## 결과물 조건 - HTML 파일 하나로 동작 - CSS/JavaScript 내부 포함 - Chrome에서 바로 실행 가능 - 별도 서버 불필요 ## 추가로 만들어줄 기능: (여기에 원하는 것을 직접 적어주세요) 예시: - 감정 버튼 (행복/슬픔/화남) — 각각 LED + 사운드 동시 제어 - LED RGB 슬라이더 - 경고 모드 버튼 — 빨간 LED 깜빡 + 사이렌 - LCD 텍스트 입력창 - 사운드 버튼 모음
