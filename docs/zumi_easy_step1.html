AI 요청 방법

💬 AI에게 이렇게 말해요

복잡하게 생각하지 말고, 원하는 걸 자연스럽게 말하면 돼요.

1️⃣ 처음 시작할 때
주미 로봇 카메라 앱을 만들어줘.
IP 입력창이랑 연결 버튼이 있고, 카메라 화면이 나오면 돼.
HTML 파일 하나로만 동작하게 해줘.
👇 AI가 만들어주면
✅ 카메라 화면이 나오는 기본 웹앱 완성!
2️⃣ 기능 추가할 때
[기존 코드에 요구사항 넣기]

이 코드에 사진 저장 버튼이랑 흑백 필터 버튼을 추가해줘.
👇 이렇게 하면
✅ 기존 앱에 새 기능이 추가됨!
3️⃣ 안 될 때
방금 만들어준 코드를 실행했는데
연결 버튼을 눌러도 아무 반응이 없어. 고쳐줘.
👇 이렇게 하면
✅ AI가 오류를 찾아서 고쳐줌!
⭐ 팁: "더 예쁘게", "모바일에서도 잘 보이게", "버튼을 더 크게" 같은 요청도 됩니다.
디자인도 AI에게 맡겨봐요!
TROUBLESHOOTING

😓 막히면 여기를 봐요

세 가지를 확인하세요:

1️⃣ IP 주소가 맞나요? 주미 LCD에 표시된 IP를 정확히 입력했는지 확인하세요.
2️⃣ 같은 Wi-Fi에 연결되어 있나요? 모바일 데이터로는 안 돼요.
3️⃣ 주미 전원이 켜져 있나요?

주미의 배터리가 부족할 수 있어요. 충전 케이블을 연결한 상태로 사용해주세요.
연결 후 2~3초 기다려보세요. 카메라가 시작하는 데 시간이 걸릴 수 있어요.

그래도 안 되면 연결 끊고 다시 연결해보세요. Chrome 브라우저를 쓰고 있는지도 확인하세요!
AI에게 이렇게 말해보세요:

"이 코드 실행했는데 [문제 내용]이 생겼어. 고쳐줘"

문제를 구체적으로 설명할수록 더 잘 고쳐줘요!
