이동 명령 정리

🗺️ 어떻게 움직일 수 있나요?

주미가 할 수 있는 이동 종류예요. AI에게 원하는 방식을 말해봐요!

▲
전진
버튼 누르는 동안 계속 앞으로 / 또는 거리 지정
▼
후진
버튼 누르는 동안 계속 뒤로 / 또는 거리 지정
↰
좌/우회전
각도 지정 가능. 90도, 180도, 360도 등
〰
라인 따라가기
바닥의 검은 선을 자동으로 따라감
✕
정지
즉시 멈춤

⚠️ 움직이기 전에 꼭 확인하세요!

  • 🚧 로봇 주변에 충분한 공간이 있는지 확인하세요.
  • 🛑 전진/후진 버튼은 누르는 동안만 움직이고 떼면 멈추게 만들어야 안전해요. AI에게 꼭 이렇게 요청하세요!
  • 🔋 배터리가 부족하면 이상하게 움직일 수 있어요. 배터리를 확인하세요.
AI 요청 예시

💬 이렇게 말해봐요

클릭하면 복사돼요!

🎮 직접 조종
전진, 후진, 좌회전, 우회전, 정지 버튼을 만들어줘. 전진이랑 후진은 누르는 동안만 움직이고 손가락을 떼면 자동으로 멈추게 해줘
⌨️ 키보드 조종
WASD 키보드로 로봇을 조종하게 해줘. W=전진, S=후진, A=좌회전, D=우회전, 스페이스=정지
📐 거리 지정
거리 슬라이더를 추가해줘. 슬라이더로 cm를 정하고 전진/후진 버튼을 누르면 그만큼 이동하게 해줘
⬛ 도형 이동
정사각형 버튼을 만들어줘. 누르면 앞으로 20cm 가고 90도 회전을 4번 반복해서 정사각형으로 움직이게 해줘
〰️ 라인 따라가기
라인트레이서 시작/정지 버튼을 만들어줘. 시작하면 바닥의 검은 선을 계속 따라가고 정지 버튼을 누르면 멈추게 해줘
✨ 이동 + 표현
전진할 때는 파란 LED가 켜지고, 후진할 때는 빨간 LED가 켜지고, 정지하면 LED가 꺼지게 해줘
⭐ 프로젝트로 말해도 돼요! "리모컨 자동차 만들어줘", "라인트레이서 로봇 만들어줘" 처럼 말해도 AI가 알아서 만들어줘요!
TROUBLESHOOTING

😓 막히면 여기를 봐요

연결 상태를 먼저 확인하세요. 연결이 됐다면 AI에게:

"이동 버튼을 눌러도 반응이 없어. buildPacket 함수와 ws.send 부분을 확인해줘"
회전은 배터리 상태나 바닥 재질에 따라 달라질 수 있어요.

AI에게 "90도 회전 각도를 조금씩 조절할 수 있게 슬라이더를 추가해줘" 라고 하면 직접 맞춰볼 수 있어요!
바닥 선이 충분히 진하고 굵어야 해요. 검정 테이프를 사용하면 가장 잘 됩니다.

AI에게 "라인트레이서 센서 민감도를 조절하는 슬라이더를 추가해줘" 라고 해보세요.
