 주미를 켜면 LCD 화면에 IP가 표시돼요. 예) 192.168.0.63
예: 192.168.0.63  ·  192.168.1.100  ·  10.0.0.5

주미가 웹앱과 통신하려면 같은 Wi-Fi 네트워크에 연결되어 있어야 합니다.
아래 순서대로 설정하면 주미가 IP 주소를 받아 연결 준비가 완료됩니다.
⚠️ 반드시 2.4GHz Wi-Fi를 사용하세요. 5GHz는 지원하지 않습니다.
0
주미 무선 설정 메뉴 진입
  1. 주미 전원을 켜고 부팅이 완료될 때까지 기다립니다.
  2. 버튼으로 [4. 무선] 메뉴로 들어갑니다.
  3. [4-5. 무선설정(설정)] → [2. Wi-Fi 설정]을 실행합니다.
1
Wi-Fi QR 코드 생성
  1. 주미 화면에 나타난 QR을 스마트폰 카메라로 스캔합니다.
  2. WiFi QR Code Generator 페이지가 열립니다.
  3. 카메라가 없다면 직접 링크를 눌러 열 수 있어요.
2
Wi-Fi QR 코드 생성
  1. 연결할 공유기의 SSID(이름)와 비밀번호를 입력 후 QR 생성합니다.
  2. 하단의 [QR 코드 생성] 버튼을 클릭하여 와이파이 정보 QR을 화면에 띄웁니다.
3
Zumi 카메라로 QR 코드 스캔
  1. 주미의 노란 버튼으로 단계를 넘기다가 "3단계: QR 준비 완료" 화면에서 녹색 버튼을 누릅니다.
  2. 화면에 scanning...이 표시되면 기기의 QR 화면을 카메라 앞 약 10~20cm에 위치시킵니다.
  3. 인식 성공 시 재부팅 후 Wi-Fi 연결이 완료됩니다.
4
와이파이 설정 완료

QR 코드가 성공적으로 인식되면 주미의 디스플레이에 아래와 같은 안내가 출력됩니다.


와이파이 연결 성공
192.168.x.xxx
설정이 완료 되었습니다

✅
파이썬 공유기?

주미가 공유기로 IP를 할당받는 모드는 파이썬 공유기입니다.

카메라 스트리밍 및 주미와의 무선 데이터 통신(파이썬 등)에 사용됩니다.

외부 프로그램에서 공유기 IP로 주미를 연동할 때도 이 모드를 실행해 주세요.

✅
연결 완료 확인
주미 화면 좌측 상단에 IP 주소(예: 192.168.0.59)가 표시되면 준비 완료입니다.
이 IP 주소를 웹앱 입력창에 입력하면 연결이 됩니다!

# ZUMI AI 카메라 웹앱 만들기 ## 시스템 구조 브라우저(HTML) ↔ WebSocket(ws://{IP}/ws) ↔ 주미 AI(하드웨어) 서버 없음. HTML 파일 하나로만 동작. ## WebSocket 연결 방법 ws = new WebSocket('ws://' + ip + '/ws') ws.binaryType = 'arraybuffer' 연결 성공(onopen) 시 반드시 아래 두 명령을 순서대로 전송: 1. ws.send('stream') → 영상 스트리밍 시작 2. ws.send('sensor') → 센서 데이터 수신 시작 ## 영상 및 센서 수신 방법 ws.onmessage = (event) => { if (typeof event.data === 'string') return; const arr = new Uint8Array(event.data); // 센서 데이터 (10바이트, 헤더 $R) if (arr.length === 10 && arr[0] === 0x24 && arr[1] === 0x52) { parseAndUpdateSensors(arr); return; } // 영상 데이터 (그 외 = JPEG) const blob = new Blob([arr], {type: 'image/jpeg'}); const url = URL.createObjectURL(blob); const img = new Image(); img.onload = () => { ctx.drawImage(img, 0, 0, w, h); URL.revokeObjectURL(url); }; img.src = url; } ## 패킷 빌더 function buildPacket(cmd, ...params) { const buf = new Uint8Array(4 + params.length); buf[0]=0x24; buf[1]=0x52; buf[2]=cmd; buf[3]=0x00; params.forEach((v,i) => buf[4+i]=v); return buf.buffer; } ## 기본 UI 요소 - IP 입력창 + 연결 버튼 + 해제 버튼 - 연결 상태 표시 (연결됨 / 연결 안 됨) - 영상 표시 canvas (width=640, height=480) ## 결과물 조건 - HTML 파일 하나로 동작 - CSS/JavaScript 내부 포함 - Chrome에서 바로 실행 가능 - 별도 서버 불필요 ## 추가로 만들어줄 기능: (여기에 원하는 기능을 직접 적어주세요) 예시: - 전체화면 버튼 추가 - 사진 저장 기능 - 흑백 필터 버튼 - 화면에 현재 시간 표시 - 밝기/대비 슬라이더
