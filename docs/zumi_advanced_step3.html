🎮 기본 이동 (직접 조종용)

함수 CMD 파라미터 설명
move_infinite 29 speed: 1~3dir: 0/1 계속 이동. 버튼 떼면 stop() 필수
dir: 0=전진, 1=후진
stop 25 - 즉시 정지
left_turn_quick 52 deg: 5~360 (5단위) 빠른 좌회전. 내부에서 deg÷5 변환
right_turn_quick 53 deg: 5~360 (5단위) 빠른 우회전. 내부에서 deg÷5 변환
# 패킷 구조 move_infinite(speed, dir) → [24][52][29][00][speed][00][dir] stop() → [24][52][25][00] left_turn_quick(deg) → [24][52][52][00][deg/5] (90도 → 18) right_turn_quick(deg) → [24][52][53][00][deg/5]

📐 정밀 이동 (거리 / 각도 지정)

함수 CMD 파라미터 설명
forward_dist 26 speed: 1~3dist: 0~300cm 지정 거리 전진 후 자동 정지
reverse_dist 26 speed: 1~3dist: 0~300cm 지정 거리 후진 후 자동 정지
left_turn 70 speed: 1~3deg: 각도 정밀 좌회전 (느리지만 정확)
right_turn 70 speed: 1~3deg: 각도 정밀 우회전 (느리지만 정확)
forward_dist(speed, dist) → [24][52][26][00][speed][dist][0] (dir=0 전진) reverse_dist(speed, dist) → [24][52][26][00][speed][dist][1] (dir=1 후진) left_turn(speed, deg) → [24][52][70][00][speed][deg_low][deg_high][0] right_turn(speed, deg) → [24][52][70][00][speed][deg_low][deg_high][1]

〰️ 특수 이동 (자동화)

함수 CMD 파라미터 설명
linefollower_infinite 30 speed: 1~3 검은 선을 계속 따라감. stop()으로 멈춤
linefollower 101 speed: 1~3time: 0~25초 지정 시간 동안 라인 따라가기
time=0이면 교차로까지
linefollower_distance 28 speed: 1~3dist: 0~255cm 지정 거리만큼 라인 따라가기
go_sensor 100 speed: 1~3senL/R: 0~255 전방 센서 감지 시 자동 정지
기본값 150 권장
linefollower_infinite(speed) → [24][52][30][00][speed] linefollower(speed,...,time) → [24][52][101][00][speed][BL][BR][BC][time×10] linefollower_distance(sp,dist) → [24][52][28][00][speed][dist] go_sensor(speed, senL, senR) → [24][52][100][00][speed][senL][senR]
💡 라인트레이서 센서값 팁: senBL/BR/BC 기본값 100을 사용하세요. 바닥 색상에 따라 50~150 사이로 조정이 필요할 수 있어요.

# ZUMI 로봇 이동 제어 웹앱 만들기 ## 시스템 구조 브라우저(HTML) ↔ WebSocket(ws://{IP}/ws) ↔ 주미 AI(하드웨어) 서버 없음. HTML 파일 하나로만 동작. ## WebSocket 연결 방법 ws = new WebSocket('ws://' + ip + '/ws') ws.binaryType = 'arraybuffer' 연결 성공(onopen) 시 반드시 아래 두 명령을 순서대로 전송: 1. ws.send('stream') → 영상 스트리밍 시작 2. ws.send('sensor') → 센서 데이터 수신 시작 ## 영상 및 센서 수신 방법 ws.onmessage = (event) => { if (typeof event.data === 'string') return; const arr = new Uint8Array(event.data); // 센서 데이터 (10바이트, 헤더 $R) if (arr.length === 10 && arr[0] === 0x24 && arr[1] === 0x52) { parseAndUpdateSensors(arr); return; } // 영상 데이터 (그 외 = JPEG) const blob = new Blob([arr], {type: 'image/jpeg'}); const url = URL.createObjectURL(blob); const img = new Image(); img.onload = () => { ctx.drawImage(img, 0, 0, w, h); URL.revokeObjectURL(url); }; img.src = url; } ## 패킷 빌더 function buildPacket(cmd, ...params) { const buf = new Uint8Array(4 + params.length); buf[0]=0x24; buf[1]=0x52; buf[2]=cmd; buf[3]=0x00; params.forEach((v,i) => buf[4+i]=v); return buf.buffer; } ## 센서 데이터 파싱 규칙 (10바이트) arr[0]: 0x24 ($) arr[1]: 0x52 (R) arr[2]: FR (전방 우측, 0~255) — 가까울수록 작아짐, 감지 기준값: 100 arr[3]: FL (전방 좌측, 0~255) — 가까울수록 작아짐, 감지 기준값: 100 arr[4]: BR (바닥 우측, 0~255) — 흰색일수록 작아짐, 감지 기준값: 30 arr[5]: BL (바닥 좌측, 0~255) — 흰색일수록 작아짐, 감지 기준값: 30 arr[6]: BC (바닥 중앙, 0~255) — 흰색일수록 작아짐, 감지 기준값: 30 arr[7]: BTN (버튼 비트마스크: 8=🔴빨강 4=🔵파랑 2=🟢초록 1=🟡노랑 / 안눌리면 '없음') 버튼 배열 순서: 빨강-파랑-초록-노랑 (수평) arr[8]: BAT (배터리 잔량, 최대 100 제한 필요) arr[9]: STAT (명령 수행 상태: 1=수행중, 0=대기중) 순차 이동 시 STAT이 0인 것을 확인한 후 다음 명령을 전송해야 함 센서값은 주미마다 개체차 있음 ## STAT 적용 규칙 STAT 체크 필요 (완료 후 다음 명령 전송): - 정밀 이동: CMD=26, 70, 50, 51, 52, 53 - 특수 이동: CMD=101, 28, 100 STAT 체크 불필요 (즉시 전송): - 버튼/키보드 조종: CMD=32 (CMD_MOTOR_INFINITE) - 라인트레이서 무한: CMD=30 - 정지: CMD=25 ## 전송 딜레이 범위: 10~200ms sendRaw() 내부에서 if (Date.now() - lastCmdTime < cmdDelay) return; CMD_STOP(25)은 딜레이 무시하고 즉시 전송 ## 모터 제어 (CMD_MOTOR_INFINITE) 버튼/키보드 조종에 적합 CMD_STOP = 25 → buildPacket(25) CMD_MOTOR_INFINITE = 32 ## 모터 패킷 생성 함수 function makeMotorPacket(dirL, speedL, dirR, speedR) { speedL = Math.max(0, Math.min(250, speedL)); speedR = Math.max(0, Math.min(250, speedR)); dirL = Math.max(0, Math.min(2, dirL)); dirR = Math.max(0, Math.min(2, dirR)); const dir = 0x40 | dirL | (dirR << 4); return buildPacket(32, speedL, speedR, dir); } ## 모터 제어(CMD_MOTOR_INFINITE) 캘리브레이션 버튼이나 키보드 조종을 원하는 경우에 함께 적용 변수 4개 (기본값 40, 범위 0~250): calGoL, calGoR, calTurnL, calTurnR 전진: makeMotorPacket(2, calGoL, 1, calGoR) 후진: makeMotorPacket(1, calGoL, 2, calGoR) 좌회전: makeMotorPacket(1, calTurnL, 1, calTurnR) 우회전: makeMotorPacket(2, calTurnL, 2, calTurnR) ## 입력 이벤트 버튼: mousedown/touchstart → 이동, mouseup/mouseleave/touchend → 정지 키보드: keydown(repeat 무시, input 포커스 시 무시) → 이동, keyup → 정지 키 매핑: w=전진 s=후진 a=좌회전 d=우회전 e=정지 ## 정밀 이동 전진 거리: CMD=26 params=[speed, dist, 0] 후진 거리: CMD=26 params=[speed, dist, 1] 좌회전 각도: CMD=70 params=[speed, deg%256, Math.floor(deg/256), 0] 우회전 각도: CMD=70 params=[speed, deg%256, Math.floor(deg/256), 1] 빠른 전진: CMD=50 params=[dist] (단위: cm, 0~300) 빠른 후진: CMD=51 params=[dist] (단위: cm, 0~300) 빠른 좌회전: CMD=52 params=[Math.round(deg/5)] (5도 단위, 최대 360도) 빠른 우회전: CMD=53 params=[Math.round(deg/5)] (5도 단위, 최대 360도) ## 특수 이동 라인트레이서 무한: CMD=30 params=[speed] 라인트레이서 시간: CMD=101 params=[speed, senBL, senBR, senBC, time×10] 기본 센서값=100 라인트레이서 거리: CMD=28 params=[speed, dist] 장애물 감지 정지: CMD=100 params=[speed, senL, senR] 기본 센서값=150 ## 기본 UI 요소 - IP 입력창 + 연결 버튼 + 해제 버튼 - 연결 상태 표시 (연결됨 / 연결 안 됨) - 영상 표시 canvas (width=640, height=480) - 방향 제어 버튼 또는 키보드 - 캘리브레이션 입력 4개 - 전송 딜레이 조절 ## 결과물 조건 - HTML 파일 하나로 동작 - CSS/JavaScript 내부 포함 - Chrome에서 바로 실행 가능 - 별도 서버 불필요 ## 추가로 만들어줄 기능: (여기에 원하는 것을 직접 적어주세요) 예시: - WASD 키보드 + D-PAD 버튼 조종 - 속도 슬라이더 (1~3) - 거리/각도 슬라이더로 정밀 이동 - 라인트레이서 시작/정지 버튼 - 정사각형 자동 이동 버튼
