STEP 2 · 표현 명령어
💡
LED 색상
CMD=10, [r][g][b] 각 0~10
예) 빨강: [10][0][0]
✨
LED 패턴
CMD=201, [패턴][시간]
1=깜빡, 6=무지개
🔊
사운드
CMD=242, [번호]
4=경적, 6=사이렌, 7=성공
📺
LCD 글씨
CMD=230, [텍스트 바이트]
UTF-8 인코딩, 최대 27바이트
💡 치트시트 내용을 그대로 AI에게 주면서 "이 명령어로 LED 버튼 만들어줘"라고 하면 더 정확한 코드가 나와요!
TROUBLESHOOTING

😓 막히면 여기를 봐요

먼저 연결 상태를 확인하세요. 연결이 끊겼다면 다시 연결 후 시도해보세요.

그래도 안 된다면 AI에게: "LED 버튼을 눌러도 반응이 없어. 패킷 전송 부분을 확인해줘" 라고 말해보세요.
한글은 UTF-8로 인코딩해야 해요. AI에게 "한글 텍스트를 UTF-8로 인코딩해서 전송하게 고쳐줘" 라고 요청해보세요.

영어로 먼저 테스트해보는 것도 좋아요!
센서 데이터 읽기

📡 로봇 상태를 읽어봐요

IR 센서, 배터리, 버튼 값을 실시간으로 화면에 표시할 수 있어요.
연결 후 "sensor" 문자열을 보내면 주미가 주기적으로 데이터를 전송합니다.

읽을 수 있는 데이터
🔴
IR 센서
전방 좌/우
하단 좌/중/우
🔋
배터리
0~100
잔량 %
🔘
버튼
눌림 여부
0 또는 1
📡 센서
IR 센서 값, 배터리 잔량, 버튼 상태를 실시간으로 화면에 표시해줘. ws.send('sensor')로 데이터를 요청하고 JSON으로 수신하는 방식으로 해줘
🔋 배터리
배터리 잔량을 화면에 게이지 바로 표시해줘. 20% 이하면 빨간색으로 경고 표시도 해줘
✨ 조합
전방 IR 센서 값이 특정 수치 이하로 떨어지면 (장애물 감지) 빨간 LED가 켜지고 경적 소리가 나게 해줘
💡 센서 데이터는 ws.send('sensor') 를 보낸 후 JSON 텍스트로 수신해요.
예: {"irFL":120,"irFR":110,"irBL":50,"irBR":48,"irBC":30,"battery":85,"btn":0}
