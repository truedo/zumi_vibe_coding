3

주미와 같은 Wi-Fi에 연결해요

내 기기(노트북, 태블릿)가 주미 로봇과 같은 Wi-Fi에 연결되어 있어야 해요.

🔍 주미 IP 주소 찾는 방법

📺
주미 화면 확인 주미를 켜면 LCD 화면에 IP가 표시돼요. 예) 192.168.0.63
IP 예시: 192.168.0.63  ·  192.168.1.100  ·  10.0.0.5
주미가 웹앱과 통신하려면 같은 Wi-Fi 네트워크에 연결되어 있어야 합니다.
아래 순서대로 설정하면 주미가 IP 주소를 받아 연결 준비가 완료됩니다.
⚠️ 반드시 2.4GHz Wi-Fi를 사용하세요. 5GHz는 지원하지 않습니다.
0
주미 무선 설정 메뉴 진입
  1. 주미 전원을 켜고 부팅이 완료될 때까지 기다립니다.
  2. 버튼으로 [4. 무선] 메뉴로 들어갑니다.
  3. [4-5. 무선설정(설정)] → [2. Wi-Fi 설정]을 실행합니다.
1
Wi-Fi QR 코드 생성
  1. 주미 화면에 나타난 QR을 스마트폰 카메라로 스캔합니다.
  2. WiFi QR Code Generator 페이지가 열립니다.
  3. 카메라가 없다면 직접 링크를 눌러 열 수 있어요.
2
Wi-Fi QR 코드 생성
  1. 연결할 공유기의 SSID(이름)와 비밀번호를 입력 후 QR 생성합니다.
  2. 하단의 [QR 코드 생성] 버튼을 클릭하여 와이파이 정보 QR을 화면에 띄웁니다.
3
주미 카메라로 QR 코드 스캔
  1. 주미 노란 버튼으로 단계를 넘기다가 "3단계: QR 준비 완료" 화면에서 녹색 버튼을 누릅니다.
  2. 화면에 scanning...이 표시되면 기기의 QR 화면을 카메라 앞 약 10~20cm에 위치시킵니다.
  3. 인식 성공 시 재부팅 후 Wi-Fi 연결이 완료됩니다.
4
와이파이 설정 완료

    QR 코드가 성공적으로 인식되면 주미 디스플레이에 아래와 같은 안내가 출력됩니다.


    와이파이 연결 성공
    192.168.x.xxx
    설정이 완료 되었습니다

🚀 연결 후 실행 방법
방법 1. 메뉴 선택
전원 켜기 → [4. 무선] → [4-2. 파이썬 공유기] 실행
방법 2. 퀵 부팅 ⭐추천
초록 버튼을 누른 채로 전원을 켜면 자동으로 파이썬 공유기가 실행됩니다.
✅
파이썬 공유기?

주미가 공유기로 IP를 할당받는 모드는 파이썬 공유기입니다.

카메라 스트리밍 및 주미와의 무선 데이터 통신(파이썬 등)에 사용됩니다.

외부 프로그램에서 공유기 IP로 주미를 연동할 때도 이 모드를 실행해 주세요.

✅
연결 완료 확인
주미 화면 좌측 상단에 IP 주소(예: 192.168.0.59)가 표시되면 준비 완료입니다.
이 IP 주소를 웹앱 입력창에 입력하면 연결이 됩니다!

HOW IT WORKS

AI에게 원하는 기능을 말로 설명하면, AI가 코드를 대신 만들어줘요.
그 파일을 열면 바로 동작합니다. 이게 전부예요.

💬 "얼굴을 인식하면 네모 박스를 그려줘"
💬 "버튼을 누르면 LED가 켜지게 해줘"
💬 "주미가 사람을 보면 인사하게 해줘"
✨ 이렇게 AI와 대화하면서 프로그램을 만드는 걸 바이브 코딩(Vibe Coding)이라고 해요.
요즘 전 세계 개발자들 사이에서 유행하고 있는 방식이에요.

🛠 시작 방법

처음이라도 걱정하지 마세요.

아래 순서대로 따라 하면 AI가 코드를 작성해주고,
여러분은 결과를 실행해보면서 기능을 추가해 나갈 수 있습니다.

1
AI를 하나 엽니다
ChatGPT, Claude, Gemini 중 편한 걸 쓰면 돼요.
뭘 써야 할지 모르겠다면 챗GPT나 제미나이를 추천해요.
2
가이드에서 "복사" 버튼을 누릅니다
각 단계마다 AI에게 보낼 말이 미리 준비되어 있어요.
버튼 하나만 누르면 복사돼요.
💡 복사되는 이 말이 바로 프롬프트(Prompt) 예요.
AI에게 보내는 요청이나 질문을 프롬프트라고 합니다.
3
AI 채팅창에 붙여넣고 전송합니다
Ctrl+V (맥은 Cmd+V) 로 붙여넣고 엔터를 누르세요.
따로 설명을 추가하지 않아도 됩니다. 💡 주미 AI에 필요한 정보가 이미 다 들어있어요.
4
AI가 만들어준 파일을 다운로드합니다
AI가 길게 코드를 써줄 거예요. 당황하지 마세요.
코드 창 오른쪽 위에 저장,다운로드버튼이 있어요. 그걸 누르면 됩니다.
5
다운로드한 파일을 더블클릭해서 실행합니다
브라우저가 자동으로 열리면서 앱이 실행돼요.
6
마음에 안 들면 AI에게 다시 요청합니다
"버튼을 더 크게 해줘", "배경색을 바꿔줘" — 뭐든 말하면 돼요.
이걸 반복하면서 기능을 하나씩 늘려가면 됩니다.

TROUBLESHOOTING

😓 막히면 여기를 봐요

가장 많이 막히는 상황들이에요. 하나씩 확인해보세요!

가장 흔한 원인 3가지를 확인하세요:

1️⃣ IP 주소가 맞나요? 주미 LCD 화면에 표시된 IP를 정확하게 입력했는지 확인하세요.

2️⃣ 같은 Wi-Fi인가요? 내 기기와 주미가 같은 Wi-Fi에 연결되어 있어야 해요. 모바일 데이터로는 안 돼요!

3️⃣ 주미가 켜져 있나요? 주미 전원이 켜진 상태인지 확인하세요.
연결 직후 1~2초 정도 기다려보세요. 카메라가 시작하는 데 시간이 걸릴 수 있어요.

그래도 안 된다면 연결을 끊었다가 다시 연결해보세요.

Internet Explorer나 오래된 브라우저를 사용 중이라면 Chrome으로 바꿔보세요.
다운로드한 파일 이름과 파일의 위치를 확인하세요.

위치가 보이지 않으면 다시 다운로드해보세요.

다운로드된 파일 아이콘이 Chrome 로고처럼 보이면 성공이에요!
이럴 때는 AI에게 이렇게 다시 요청해보세요:

"방금 만들어준 코드를 실행했는데 [어떤 문제]가 생겼어. 고쳐줘"

문제를 구체적으로 설명할수록 AI가 더 잘 고쳐줘요.
예: "연결 버튼을 눌렀는데 아무 반응이 없어", "화면이 하얗게만 나와"
Android 스마트폰의 Chrome 브라우저에서는 잘 됩니다!

HTML 파일을 Google Drive나 카카오톡으로 전송한 뒤, Chrome으로 열어보세요.

⚠️ iPhone(iOS)은 Safari 브라우저 제한으로 잘 안 될 수 있어요. 가능하면 PC나 Android를 사용하세요.
