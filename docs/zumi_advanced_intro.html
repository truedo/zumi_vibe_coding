준비됐나요?
지금 바로 시작해봐요 🚀

Step 1부터 차근차근, 또는 바로 원하는 단계로 뛰어들어도 됩니다!

Step 1 시작하기 →

주미가 웹앱과 통신하려면 같은 Wi-Fi 네트워크에 연결되어 있어야 합니다.
아래 순서대로 설정하면 주미가 IP 주소를 받아 연결 준비가 완료됩니다.
⚠️ 반드시 2.4GHz Wi-Fi를 사용하세요. 5GHz는 지원하지 않습니다.
0
주미 무선 설정 메뉴 진입
  1. 주미 전원을 켜고 부팅이 완료될 때까지 기다립니다.
  2. 버튼으로 [4. 무선] 메뉴로 들어갑니다.
  3. [4-5. 무선설정(설정)] → [2. Wi-Fi 설정]을 실행합니다.
1
Wi-Fi QR 코드 생성
  1. 주미 화면에 나타난 QR을 스마트폰 카메라로 스캔합니다.
  2. WiFi QR Code Generator 페이지가 열립니다.
  3. 카메라가 없다면 직접 링크를 눌러 열 수 있어요.
2
Wi-Fi QR 코드 생성
  1. 연결할 공유기의 SSID(이름)와 비밀번호를 입력 후 QR 생성합니다.
  2. 하단의 [QR 코드 생성] 버튼을 클릭하여 와이파이 정보 QR을 화면에 띄웁니다.
3
Zumi 카메라로 QR 코드 스캔
  1. 주미의 노란 버튼으로 단계를 넘기다가 "3단계: QR 준비 완료" 화면에서 녹색 버튼을 누릅니다.
  2. 화면에 scanning...이 표시되면 기기의 QR 화면을 카메라 앞 약 10~20cm에 위치시킵니다.
  3. 인식 성공 시 재부팅 후 Wi-Fi 연결이 완료됩니다.
4
와이파이 설정 완료

QR 코드가 성공적으로 인식되면 주미의 디스플레이에 아래와 같은 안내가 출력됩니다.


와이파이 연결 성공
192.168.x.xxx
설정이 완료 되었습니다

🚀 연결 후 실행 방법
방법 1. 메뉴 선택
전원 켜기 → [4. 무선] → [4-2. 파이썬 공유기] 실행
방법 2. 퀵 부팅 ⭐추천
초록 버튼을 누른 채로 전원을 켜면 자동으로 파이썬 공유기가 실행됩니다.
✅
파이썬 공유기?

주미가 공유기로 IP를 할당받는 모드는 파이썬 공유기입니다.

카메라 스트리밍 및 주미와의 무선 데이터 통신(파이썬 등)에 사용됩니다.

외부 프로그램에서 공유기 IP로 주미를 연동할 때도 이 모드를 실행해 주세요.

✅
연결 완료 확인
주미 화면 좌측 상단에 IP 주소(예: 192.168.0.59)가 표시되면 준비 완료입니다.
이 IP 주소를 웹앱 입력창에 입력하면 연결이 됩니다!
