HOW TO START

시작 방법

처음이라도 걱정하지 마세요.
딱 이 순서대로만 따라하면 됩니다.

아래 순서대로 따라 하면 AI가 코드를 작성해주고,
여러분은 결과를 실행해보면서 기능을 추가해 나갈 수 있습니다.

1
AI를 하나 엽니다
ChatGPT, Claude, Gemini 중 편한 걸 쓰면 돼요.
뭘 써야 할지 모르겠다면 챗GPT나 제미나이를 추천해요.
2
가이드에서 "복사" 버튼을 누릅니다
각 단계마다 AI에게 보낼 말이 미리 준비되어 있어요.
버튼 하나만 누르면 복사돼요.
💡 복사되는 이 말이 바로 프롬프트(Prompt) 예요.
AI에게 보내는 요청이나 질문을 프롬프트라고 합니다.
3
AI 채팅창에 붙여넣고 전송합니다
Ctrl+V (맥은 Cmd+V) 로 붙여넣고 엔터를 누르세요.
따로 설명을 추가하지 않아도 됩니다. 💡 주미 AI에 필요한 정보가 이미 다 들어있어요.
4
AI가 만들어준 파일을 다운로드합니다
AI가 길게 코드를 써줄 거예요. 당황하지 마세요.
코드 창 오른쪽 위에 저장,다운로드버튼이 있어요. 그걸 누르면 됩니다.
5
다운로드한 파일을 더블클릭해서 실행합니다
브라우저가 자동으로 열리면서 앱이 실행돼요.
6
마음에 안 들면 AI에게 다시 요청합니다
"버튼을 더 크게 해줘", "배경색을 바꿔줘" — 뭐든 말하면 돼요.
이걸 반복하면서 기능을 하나씩 늘려가면 됩니다.
